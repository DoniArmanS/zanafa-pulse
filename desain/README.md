# desain/

Semua bahan visual: wireframe, mockup, dan aset gambar.

**Penanggung jawab:** System Analyst (Yesi, Kayla) dan Frontend (Sarwenda, Zahra)

## Yang dimasukkan ke sini

| Subfolder | Isi | Contoh nama file |
|---|---|---|
| `wireframe/` | Wireframe per layar, ekspor PNG + file sumber (Figma/Balsamiq link di README) | `03-katalog-buku.png` |
| `mockup/` | Desain berwarna / versi revisi dari wireframe | `03-katalog-buku-v2.png` |
| `aset/` | Logo, ikon, foto sampul buku yang akan dipakai aplikasi | `logo-zanafa.svg` |

## Aturan penamaan

- Huruf kecil, pakai tanda hubung, diawali nomor urut layar: `01-login.png`, `02-dashboard-staff.png`.
- Revisi diberi akhiran `-v2`, `-v3`. Jangan menimpa versi lama, supaya perubahan bisa dibandingkan.
- Kalau ada file sumber besar (Figma), cukup tulis link-nya di file `LINK.md`, jangan unggah file ratusan MB.

## Kenapa perlu folder ini

Wireframe di sini adalah acuan tampilan frontend. Kalau layar berubah, ubah wireframe-nya dulu di sini lewat pull request, supaya tim bisa melihat dan menyetujui perubahannya sebelum kode diubah.
