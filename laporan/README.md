# laporan/

Dokumen akademik proyek yang dikumpulkan ke dosen.

**Penanggung jawab:** Seluruh anggota, dikoordinasi Project Manager (Doni)

## Yang dimasukkan ke sini

| Subfolder | Isi |
|---|---|
| `proposal/` | Project Initiation, revisi-revisinya |
| `analisis/` | Analisis & Perancangan Sistem: kebutuhan, use case, class diagram, sequence diagram (PDF + file sumber `.puml` / `.vpp`) |
| `laporan-akhir/` | Laporan akhir, lampiran |
| `presentasi/` | Slide presentasi tiap progres, poster A1 kompetisi |

## Aturan

- Simpan dalam **PDF** untuk versi yang dikumpulkan, plus file sumbernya (`.docx`, `.pptx`) agar bisa direvisi.
- Nama file: `YYYY-MM-DD_judul-singkat.pdf`, contoh `2026-10-12_analisis-perancangan-v3.pdf`.
- Satu file satu topik. Jangan unggah dalam bentuk `.zip`, karena isinya tidak bisa dilihat dan dibandingkan di GitHub.

## Kenapa perlu folder ini

Folder `Dokumentasi/` di laptop Doni tidak ikut ke GitHub. Folder ini adalah versi bersama yang bisa diakses dan direvisi seluruh anggota, dan riwayat revisinya tercatat.
